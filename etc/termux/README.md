# Upload Photos Script v2 - WiFi & Later

Обновлённый скрипт автозагрузки фотографий с Termux на сервер.

## Новая функциональность

### Диалог - Bottom Sheet:

При обнаружении нового фото показывается список снизу экрана:

```
                              
┌─────────────────────────────┐
│  📸 IMG_20260408.jpg        │ ← Заголовок
├─────────────────────────────┤
│  Сейчас                     │ ← Нажми один раз
│─────────────────────────────│
│  WiFi                       │
│─────────────────────────────│
│  Позже                      │
│─────────────────────────────│
│  Пропустить                 │
└─────────────────────────────┘
```

**Один клик по варианту - готово!** Нет лишних OK/Cancel.

---

## Варианты действий

### 1. **Сейчас**
- Загружает файл немедленно (как было раньше)
- Использует текущее подключение (WiFi или мобильный интернет)

### 2. **WiFi**
- Ждёт подключения к WiFi **до 4 часов** (настраивается константой `WIFI_WAIT_TIMEOUT`)
- Проверяет WiFi каждые **10 минут** (константа `WIFI_CHECK_INTERVAL`)
- Если WiFi найден → загружает файл
- Если таймаут → автоматически переходит в режим **"Позже"**

**Логика:**
```
Нажал "WiFi"
    ↓
Проверка WiFi каждые 10 мин
    ↓
WiFi найден? → Загрузка файла ✅
    ↓
Прошло 4 часа? → Переход в "Позже" ⏸️
```

### 3. **Позже**
- Файл добавляется в очередь отложенных (`~/tmp/pending_uploads.txt`)
- Создаётся **постоянное уведомление** с кнопкой "Загрузить"
- Нажатие на уведомление → показывает диалог снова (можно выбрать любой вариант)

**Логика:**
```
Нажал "Позже"
    ↓
Файл в очередь
    ↓
Создано уведомление "⏸️ Отложено: IMG_001.jpg"
    ↓
Пользователь нажал "Загрузить"
    ↓
Показывается диалог снова (Сейчас/WiFi/Позже/Пропустить)
```

### 4. **Пропустить**
- Файл **НЕ загружается** вообще
- Показывается уведомление "⏭️ Пропущено"
- Больше никаких действий с этим файлом

## Настройки

### WiFi параметры (строки 31-32):

```bash
WIFI_WAIT_TIMEOUT=14400     # Время ожидания WiFi (4 часа = 14400 сек)
WIFI_CHECK_INTERVAL=600     # Проверка каждые 10 минут (600 сек)
```

**Изменить время ожидания WiFi:**
- 1 час = 3600
- 2 часа = 7200
- 4 часа = 14400 (по умолчанию)
- 8 часов = 28800

**Изменить интервал проверки:**
- 5 минут = 300
- 10 минут = 600 (по умолчанию)
- 30 минут = 1800

```
~/upload_photos.sh
```

### Триггер для уведомлений:
```
~/.termux/upload_trigger.sh

```

Список путей к файлам, которые ждут загрузки.

```
~/tmp/upload_trigger_queue.txt
```
Внутренний файл для обработки нажатий на уведомления.

## Как работает система уведомлений

### Создание уведомления:
```bash
termux-notification \
    --id "abc12345" \              # ID = хеш имени файла
    --title "⏸️ Отложено: IMG_001.jpg" \
    --content "Нажмите для загрузки" \
    --ongoing \                     # Постоянное уведомление
    --button1 "Загрузить" \
    --button1-action "upload_trigger.sh '/path/to/file'"
```

### Нажатие на кнопку:
1. Запускается `upload_trigger.sh`
2. Путь к файлу добавляется в `upload_trigger_queue.txt`
3. Фоновый процесс читает очередь
4. Показывается диалог выбора снова

### Удаление уведомления:
- После успешной загрузки
- Автоматически при повторном выборе "Позже"

## Множественные файлы

**Каждый файл** имеет:
- ✅ Свой диалог
- ✅ Своё уведомление (если отложен)
- ✅ Свою запись в очереди

**Пример:**
```
IMG_001.jpg → Выбрано "WiFi" → Ждёт WiFi
IMG_002.jpg → Выбрано "Позже" → В уведомлениях
IMG_003.jpg → Выбрано "Сейчас" → Загружается
```

Все **независимы** друг от друга!

## Сценарии использования

### Сценарий 1: Экономия трафика
```
1. Сделал фото на улице (мобильный интернет)
2. Выбрал "WiFi"
3. Скрипт ждёт пока придёшь домой
4. Подключился WiFi дома → автоматическая загрузка
```

### Сценарий 2: Отложенная обработка
```
1. Сделал 10 фото подряд
2. На все выбрал "Позже"
3. Вечером нажал на уведомления
4. Выбрал "Сейчас" для каждого
```

### Сценарий 3: Комбинированный
```
1. Важное фото → "Сейчас" (загружается немедленно)
2. Обычное фото → "WiFi" (подождёт WiFi)
3. Скриншот → "Позже" (вручную потом)
```

## Технические детали

### Проверка WiFi:
```bash
is_wifi_connected() {
    local WIFI_INFO
    WIFI_INFO=$(termux-wifi-connectioninfo 2>/dev/null)
    
    if echo "$WIFI_INFO" | grep -q '"ssid"'; then
        return 0  # WiFi подключен
    fi
    return 1
}
```

Использует `termux-wifi-connectioninfo` для определения WiFi.

### Хранение отложенных файлов:
```
/path/to/file1.jpg
/path/to/file2.jpg
/path/to/file3.jpg
```

Простой текстовый файл - один путь на строку.

### ID уведомлений:
```bash
NOTIF_ID=$(echo "$BASENAME" | md5sum | cut -d' ' -f1 | cut -c1-8)
```

Хеш имени файла → уникальный ID → можно удалить конкретное уведомление.

## Установка

### Первая установка:

```bash
# 1. Установить необходимые пакеты (если ещё не установлены)
pkg install termux-api inotify-tools curl sshpass openssh -y

# 2. Настроить доступ к хранилищу (если ещё не настроено)
termux-setup-storage

# 3. Создать директорию boot и скопировать скрипт
mkdir -p ~/.termux/boot
cp upload_photos.sh ~/.termux/boot/upload_photos.sh
chmod +x ~/.termux/boot/upload_photos.sh

# 4. Запустить скрипт
~/.termux/boot/upload_photos.sh &
```

### Обновление существующей версии:

```bash
# 1. Остановить старую версию (проверяем что запущена)
if pgrep -f "upload_photos.sh" > /dev/null; then
    echo "Останавливаю старую версию..."
    pkill -f upload_photos.sh
    sleep 2
else
    echo "Скрипт не запущен"
fi

# 2. Скопировать новую версию
cp upload_photos.sh ~/.termux/boot/upload_photos.sh
chmod +x ~/.termux/boot/upload_photos.sh

# 3. Запустить новую версию
~/.termux/boot/upload_photos.sh &

# 4. Проверить что запустилась
sleep 2
if pgrep -f "upload_photos.sh" > /dev/null; then
    echo "✅ Скрипт успешно запущен"
else
    echo "❌ Ошибка запуска"
fi
```

### Защита от дублирования (встроенная в скрипт):

Скрипт автоматически проверяет что он не запущен дважды:

```bash
# Встроенная проверка в начале скрипта
RUNNING_COUNT=$(pgrep -fc "$SCRIPT_NAME")

if [ "$RUNNING_COUNT" -gt 2 ]; then
    termux-toast "⚠️ Upload script already running"
    exit 0
fi
```

### Автозапуск при загрузке телефона:

**Требования:**
1. Установлен **Termux:Boot** app (из F-Droid/Google Play)
2. Разрешения на автозапуск для Termux
3. Скрипт в `~/.termux/boot/` (уже там после установки)

**После перезагрузки телефона:**
- Termux:Boot автоматически запустит `upload_photos.sh`
- Скрипт начнёт мониторинг Camera
- Wake-lock предотвратит засыпание Termux

### Проверка работы:

```bash
# Проверить что скрипт запущен
pgrep -fa upload_photos.sh

# Должен показать:
# 12345 /data/data/com.termux/.../boot/upload_photos.sh

# Проверить очередь отложенных
cat ~/tmp/pending_uploads.txt

# Посмотреть уведомления Termux
termux-notification-list
```

### Где находятся файлы:

```
~/.termux/boot/upload_photos.sh  ← Основной скрипт (единственная копия)
~/tmp/upload_trigger.sh          ← Триггер для уведомлений (создаётся автоматически)
~/tmp/pending_uploads.txt        ← Очередь отложенных файлов
~/tmp/upload_trigger_queue.txt   ← Очередь триггеров (внутренний)
```

## Известные ограничения

1. **WiFi проверка работает только когда скрипт запущен**
   - Если скрипт остановлен → проверка WiFi останавливается
   - Решение: использовать Termux:Boot для автозапуска

2. **Уведомления удаляются при перезагрузке**
   - Android удаляет уведомления при перезагрузке
   - Очередь файлов сохраняется в `pending_uploads.txt`
   - При следующем запуске можно пересоздать уведомления

3. **Максимум времени ожидания WiFi ограничен**
   - Android может убить процесс при долгом ожидании
   - Рекомендуется не больше 8 часов

## FAQ

**Q: Что если WiFi подключится через 5 часов?**
A: Файл перейдёт в "Позже" после 4 часов таймаута. Нужно вручную нажать на уведомление.

**Q: Можно ли изменить варианты в диалоге?**
A: Да, измени строку 121:
```bash
-v "Сейчас,WiFi,Позже"
# На например:
-v "Now,WiFi,Later,Cancel"
```

**Q: Как очистить всю очередь отложенных?**
A: 
```bash
rm ~/tmp/pending_uploads.txt
touch ~/tmp/pending_uploads.txt
```

**Q: Можно ли добавить 4-й вариант?**
A: Да! Добавь в диалог и в `case` обработчик.
